The initial planned subreddit is r/funnyvideos, subject to approval and content availability.

ReelHub is a standalone application, not a bot that will be installed in or post to this subreddit. It would only retrieve public video posts through approved read-only API access. It would not post, comment, vote, send messages, or perform moderation actions.

The initial testing scope will be limited to this subreddit. Any expansion would follow the applicable access conditions and requirements.
